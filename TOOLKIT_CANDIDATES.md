# Toolkit candidates

These are proposals for later extraction, not changes to the toolkit. Branding, business copy, artwork, and project data must stay in this portfolio. Each proposal needs review and verification before promotion.

| Candidate / source                                                     | Reusable behavior                                                                                                                   | Dependencies and customization                                                                                                             | Accessibility / next validation                                                                                                         |
| ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| `ResponsiveNavigation` / `src/components/ui/responsive-navigation.tsx` | Desktop links and mobile disclosure; Escape closes and restores toggle focus; link selection and desktop breakpoint reset the menu. | React only. Brand, items and CTA supplied as props. Map navigation classes to semantic tokens; keep CSS and matchMedia breakpoint aligned. | Labeled nav, native button, expanded/controls state. Verify keyboard, screen readers, resize with open menu and long labels on devices. |
| `ButtonLink` / `src/components/ui/button-link.tsx`                     | Semantic anchor with primary/secondary styling and decorative arrow.                                                                | React. Destination, label and variant supplied as props. No router dependency.                                                             | Visible focus, 50px target, reduced-motion hover. Verify light theme and contrast after token remapping.                                |
| `Section` / `src/components/ui/section.tsx`                            | Labeled section, optional description, content container.                                                                           | React. ID, index, labels and children supplied as props.                                                                                   | Unique heading IDs, semantic h2. Check long headings and localized text.                                                                |
| `ProjectCard` / `src/components/project-card.tsx`                      | Explicit empty preview state with project identity.                                                                                 | React. Content and accent variant supplied as props.                                                                                       | Article/h3, noninteractive until a real destination exists. Define approved image/link states only when needed.                         |
| `ServiceCard` / `src/components/service-card.tsx`                      | Compact service presentation with number, symbol, heading and description.                                                          | React. All copy supplied as props.                                                                                                         | Decorative symbol hidden from assistive technology. Test long copy and alternate heading hierarchy before extraction.                   |
| `ContactChannel` / `src/components/contact-channel.tsx`                | Contact link only when a value and destination exist; otherwise clear placeholder.                                                  | React. Label/value/href supplied as props.                                                                                                 | No dead links. Validate external URL and email conventions when real channels are provided.                                             |
| CSS motion / `src/app/globals.css`                                     | Lightweight hover, smooth anchor scrolling, reduced-motion and forced-colors treatment.                                             | CSS only. Map brand tokens to neutral semantics.                                                                                           | No entrance-hidden content. Manual reduced-motion/forced-colors review remains.                                                         |

Example composition: `<Section id="work" index="01" eyebrow="WORK" title="Selected projects">…</Section>`. All components have explicit TypeScript props. Formatting, lint, strict types and build are verified at project level; this is not yet a standalone, published component library. Components were authored for this owner-controlled project and have no separate third-party source license.

Potential toolkit documentation improvements: a portable provenance snapshot format, an asset-preservation checklist, and a contact placeholder convention. No automatic transfer is authorized or performed during Milestone 1.
